# GovWait bundled data notice

This package contains GovWait-generated JSON files derived from publicly
available government processing-time publications. The files preserve the
originating agency, official source URL, source date when supplied, verification
time, unit, and source-specific reuse note.

This notice is informational. It does not grant additional rights in the
underlying government information, and a software licence for GovWait-owned code
does not relicense that information.

Source families currently represented in the bundle:

- United Kingdom: covered Crown content is generally available under the Open
  Government Licence v3.0, subject to its attribution requirements and
  exceptions.
- New Zealand: covered Crown website content is offered under Creative Commons
  Attribution 3.0 New Zealand, subject to the stated attribution requirements
  and exceptions.
- Canada: Canada.ca general terms and the Open Government Licence - Canada are
  distinct. Do not assume every IRCC resource uses the open licence; check the
  originating resource before commercial redistribution.
- Norway: GovWait has not identified an explicit reuse licence on the tracked
  UDI waiting-time pages. The bundle retains attributed factual values and source
  links rather than UDI page prose, logos, or design.

Review each record's `source_url` and `license_note`, plus the current guidance
at <https://govwait.com/data-license/>, before reuse. Government marks, logos,
third-party material, and page design are not included in any GovWait software
licence.

GovWait provides the bundle without a promise that a value is current for a
particular person's case. It is general information, not legal or immigration
advice.
